# ADR 0001: Shim монтирует текущий каталог по флагу

## Status
Implemented

## Context
Часть CLI‑инструментов требует доступа к файлам проекта в текущем каталоге. Без монтирования `$PWD` в контейнер такие инструменты не работают.

## Decision
Добавить флаг `cli2docker shim --mount-cwd`, который встраивает в shim:
- `-v "${PWD}:/work"`
- `-w /work`

Shim остаётся без собственных флагов и просто прокидывает аргументы в `docker run`.

## Consequences
- По умолчанию поведение не меняется.
- С `--mount-cwd` контейнер получает доступ к текущему каталогу хоста.
- Точка монтирования фиксирована (`/work`).

## Alternatives
- Монтировать `$PWD` по умолчанию (отклонено, opt‑in).
- Позволить задавать путь внутри контейнера (отложено).
