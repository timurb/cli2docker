# ADR 0006: Прототипы в bash/python/go для сравнения

## Status
Superseded

## Context
Нужно было сравнить несколько реализаций MVP перед выбором основного стека.

## Decision
Сделать три прототипа CLI: bash, python и go, чтобы сравнить и оставить один.

## Consequences
- На этапе прототипирования существовали три реализации.
- В текущем репозитории оставлена Go‑версия, скриптовые прототипы удалены.

## Alternatives
- Сразу выбрать один язык и не тратить время на сравнение.
