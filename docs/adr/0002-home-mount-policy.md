# ADR 0002: Монтирование каталога из $HOME

## Status
Implemented

## Context
Некоторым инструментам нужен доступ к пользовательской конфигурации в `$HOME` (например, `~/.codex`). Требуется ограничить поверхность доступа и избежать произвольных монтирований.

## Decision
Добавить флаги:
- `cli2docker shim --mount-home <path>` — монтирует каталог из `$HOME` в `$HOME` контейнера (read‑only).
- `cli2docker shim --mount-home-rw` — переключает режим в read‑write.

Правила:
- Допускается только один путь.
- Путь обязан быть внутри `$HOME`; иначе ошибка.
- Путь резолвится на машине генерации shim.
- Монтирование внутри контейнера — `/home/node/<relative-from-home>`.

## Consequences
- Монтирование по умолчанию выключено.
- По умолчанию используется `:ro`.
- Нельзя монтировать произвольные пути вне `$HOME`.

## Alternatives
- Разрешить произвольные пути (отклонено).
- Поддержать список путей (отложено).
- Настраиваемый контейнерный HOME (отложено).
